## Milestone 3 Entry: Listen Server Combat Smoke Test

Use this before adding more content.

- `Number of Players = 2`.
- `Net Mode = Play As Listen Server`.
- Prefer `New Editor Window` so both clients are visible.
- Host movement: `WASD`.
- Client movement fallback: arrow keys are also mapped.
- Host and client can both fire with `LMB`.
- Host and client can request shockwave with `Q` or right mouse.
- Host and client can request dash with `Space`.
- Shockwave damage is server-authoritative: enemy health/death should match on both windows.
- Dash position is replicated: the other window should see the moved character.
- Reward options are generated by the server and visible on both windows.
- Reward selection by either player should advance the room exactly once.
- Victory and defeat state should match on host and client.
