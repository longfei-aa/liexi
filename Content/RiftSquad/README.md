# RiftSquad Content Layout

Binary Unreal assets are created in the editor and should live under this folder.

## Required Milestone 0 Assets

- `Maps/M_Greybox_CombatRoom.umap`
- `Input/IMC_Player.uasset`
- `Input/IA_Move.uasset`
- `Input/IA_Fire.uasset`

## Required Milestone 1 Assets

- `Characters/BP_RiftPlayerCharacter.uasset`
- `Enemies/BP_ChaserEnemy.uasset`
- `Rooms/BP_RiftRoomManager.uasset`
- `UI/WBP_CombatHUD.uasset`

## Directory Ownership

- `Characters/`: playable character blueprints and meshes
- `Enemies/`: enemy blueprints and meshes
- `Weapons/`: projectile and attack presentation assets
- `Rooms/`: room manager blueprints and room prefab helpers
- `UI/`: UMG widgets
- `VFX/`: Niagara and materials for combat feedback
- `SFX/`: temporary and final sound effects
- `Data/`: DataAssets and DataTables
- `Maps/`: playable and test maps
- `ThirdPartyAssets/`: raw imported assets with source and license notes
